3. Justificación
Las bases de datos son ampliamente utilizadas en las organizaciones, se utilizan bases de datos relacionales así como bases de datos 
no relacionales llamadas NOSQL, las cuales han surgido como respuesta a necesidad de almacenar datos más complejos y obtener 
rápido almacenamiento y procesar grandes volúmenes de datos sin estructura, semiestructurados y estructurados.
Este curso tiene 
como propósito la profundización en el manejo conceptos de bases de datos relacionales, manejo de SQL y programación a nivel de 
base de datos, así como la apropiación de conceptos relacionados con el diseño, desarrollo y gestión de Bases de Datos NoSQL y de 
tendencias tecnológicas habilitadas a través del uso de base de datos que permita ampliar los conocimientos sobre Bases de Datos 
adquiridos por el estudiante en el curso anterior.
